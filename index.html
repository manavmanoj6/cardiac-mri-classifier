Introduction

This project showcases a deep learning model designed to analyze cardiac Magnetic Resonance Imaging (MRI) scans. By leveraging advanced computer vision techniques, the model can classify heart conditions, specifically distinguishing between a normal heart and various types of cardiomyopathy.

The goal is to provide a fast, accessible tool that demonstrates the power of AI in medical imaging. Navigate to the Classifier section to upload an image and see the model in action.

About The Project

This tool uses a hybrid AI system. First, a custom convolutional neural network (CNN), built with TensorFlow and fine-tuned on the ACDC and M&Ms datasets, performs an initial classification. This result provides context for a second, more powerful model.

The image and the initial classification are then sent to Google's Gemini, a large multimodal model. Gemini analyzes the visual information in the context of the prediction to generate a dynamic, detailed description of the heart's condition. This two-step process leverages both a specialized classifier for accuracy and a generalist LLM for descriptive power.
