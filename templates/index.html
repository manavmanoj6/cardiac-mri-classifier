Introduction

This project showcases a deep learning model designed to analyze cardiac Magnetic Resonance Imaging (MRI) scans. By leveraging advanced computer vision techniques, the model can classify heart conditions, specifically distinguishing between a normal heart and various types of cardiomyopathy.

The goal is to provide a fast, accessible tool that demonstrates the power of AI in medical imaging. Navigate to the Classifier section to upload an image and see the model in action.

About The Project

This tool was built using a multi-stage process. The core classifier is a Convolutional Neural Network (CNN) built with TensorFlow/Keras, utilizing a MobileNetV2 architecture. It was trained using transfer learning on a combined dataset of cardiac MRI scans from the ACDC and M&Ms challenges, allowing it to accurately classify several conditions.

To provide more insightful analysis, the application uses a hybrid AI system. After the initial classification, the image and the predicted condition are sent to Google's Gemini, a large multimodal model. Gemini analyzes the visual information to generate a unique, detailed description of the heart's visible features, complementing the classification with a descriptive summary.
